Where the numbers come from

Every figure carries the date it was captured and links to the provider's own page. Prices for Akamai, Vultr, Scaleway and Microsoft Azure refresh daily from those providers' public pricing APIs; the rest are dated manual captures, and each figure says which it is. A failed refresh keeps the previous value and marks it stale rather than blanking it.

Where a value could not be established the page says so. A blank is never rendered as a zero, and a provider whose figures could not be obtained never ranks first by virtue of being undocumented. If something here is wrong, open an issue with the provider, the figure, and a link to the page that contradicts it.
